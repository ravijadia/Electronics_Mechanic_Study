# Gujarati glossary for the Virtual Lab (APPROVED by the instructor)

Used for every `*.gu.ts` file so the same term is always written the same way.

## Rules

1. **Gujarati word** when a plain, well-known Gujarati word exists (અવરોધ, પ્રવાહ, શ્રેણી, સમાંતર, ઢાળ).
2. **Transliterate** device and instrument names (ડાયોડ, ટ્રાન્ઝિસ્ટર, મલ્ટીમીટર), as on the shop floor.
3. **English in brackets** the first time a term appears in a practical, e.g. `અવરોધક (resistor)`.
4. **Always English:** symbols, units, part numbers (BC547, 7805), bench labels, button names ("Record reading"), signal names (Vcc, GND).
5. **Digits:** 0–9, as in the record book.
6. **Sentences:** short and direct, like the English steps. Imperative form (“મૂકો”, “દબાવો”).
